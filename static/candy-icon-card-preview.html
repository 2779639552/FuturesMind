插入指南 本轮未插入生产页

你选择了「先不放了」，所以 web_template.html 里**没有**这段组件。 将来要放进去时，有一个必须先处理的冲突：

类名冲突：本项目已把 .card 当作主面板类用（padding:18px 20px、 border-radius、box-shadow、background 等），而组件根节点也叫 .card。直接贴进去，那 190×254 的盒子会被加上内边距、圆角、阴影与卡面底色，1:1 立刻破功。 隔离配方（不改组件任何声明，只加一层前缀祖先 + 抵消泄漏）：

/* 1) 外面套一层带前缀的容器（新加，不动原组件选择器） */ <div class="acx-showcase"><div class="card">…</div></div> /* 2) 组件选择器整体前缀化，前缀化后特异性(0,2,0)高于项目 .card(0,1,0)， 组件自己声明的 6 个属性会自动赢 */ .acx-showcase .card { /* 原 6 行声明逐字保留 */ } .acx-showcase .card .item { /* 原样 */ } .acx-showcase .item:hover { /* 原样 */ } /* 3) 只补"组件没声明、但项目 .card 会泄漏进来"的属性，把它们清零 */ .acx-showcase .card { padding: 0; border: 0; border-radius: 0; background: none; box-shadow: none; transition: none; } /* 4) 组件本身无 @keyframes，无需处理作用域问题 */

另外两点注意：① .item:hover 的放大 1.95 倍 + overflow: visible 会盖住相邻元素， 这是原组件在"展示墙"语境下的设计，放进密集的业务页面需谨慎（本轮按你的选择只在组件内保留原样）； ② 四格里的 .quantity 继承 .card 的 color: white， 白字压在浅紫底 #c7c7ff 上对比度很低，这是原组件的特征，已按原样保留。
