📖 子模块说明 点击展开▶
异常检测：Z-score = (当日情绪 - 7日均值) / 7日标准差。\|Z\|>2 = 情绪显著偏离近期均值。
分歧度：1 - \|看多%-看空%\|。高=共识强，低=市场严重分歧（可能反转）。
领先滞后：计算情绪→价格 和 价格→情绪的时滞相关系数，判断谁领先谁。
品种对比：多品种横截面比较，看哪些品种情绪最强/最弱。
跨平台：微博(散户)、知乎(专业)、小红书(社交)三方情绪差异。分歧大=信号不可靠。
作者：影响力 = 发帖量×0.3 + log(粉丝)×0.3 + log(互动)×0.4。
事件：从帖子中提取关键词匹配的8类事件（停产/政策/进出口/天气/矿山/地缘/库存/宏观）。

原版 TradingAgents 框架

TradingAgents 是 TauricResearch 开源的多智能体金融投研框架（65K+ Stars），原版面向美股市场。

原版架构

阶段节点说明
1. 分析师Market / Social / News / Fundamentals4位分析师串行运行，各自调用数据工具生成报告
2. 辩论Bull Researcher vs Bear Researcher基于分析师报告进行多轮对抗辩论，每方可引用数据反驳对方
3. 研究Research Manager审阅辩论记录，输出结构化投资计划（Buy/Overweight/Hold/Underweight/Sell）
4. 交易Trader基于研究计划制定具体交易（入场价/止损/仓位）
5. 风控Aggressive / Neutral / Conservative3位风控分析师进行三方辩论，评估风险
6. 决策Portfolio Manager综合研究+交易+风控，输出最终交易决策

原版局限性

  1. 串行分析师：4位分析师依次运行，4倍耗时，错误通过共享状态传播
  2. "传话游戏"效应：数据→分析师→辩论→研究→交易→风控→决策，5次LLM传递，精确数据退化为模糊文字
  3. 美股硬编码：4层代码深度绑定美股数据源（Alpha Vantage/Yahoo Finance/Reddit）
  4. 风控后置：风控在交易决策之后，方向已定无法修正
  5. 权重黑箱：LLM隐式判断权重，无可编程/可审计的权重机制

📖 策略说明 点击展开▶
固定持仓(情绪)：当情绪得分绝对值超过阈值时入场，固定持仓N天平仓。
情绪反转出场：入场后持有直到情绪翻转到对立方向（或达到最大持仓天数）。
基本面vs情绪对比：纯基本面(趋势+动量+量) vs 基本面+情绪共振。三曲线同图对比。

信号阈值：只交易 \|情绪得分\| > 阈值的信号。0.1=高频，0.3=低频但质量高。
胜率：盈利笔数/总笔数。>50%=优于随机。
年化夏普：(年化收益-无风险利率)/年化波动率。>1=优秀，>2=出色。
索提诺比率：类似夏普但只惩罚下行波动（下跌风险），更能反映真实风险调整收益。
卡玛比率：年化收益/最大回撤，衡量每单位回撤的回报。>0.5=良好。
年化波动率：收益率的标准差年化值。低波动=策略稳定。
盈亏比(Profit Factor)：总盈利/总亏损。>1.5=良好，>2=优秀。
最大回撤：累计收益从峰值回落的最大幅度。
基本面因子：趋势(60%) + 动量(25%) + 成交量(15%)，合成 fund_score ∈ [-1,+1]。
