## 二、各平台详细分析

### 2.1 微信/公众号 — 🔴 最困难

**搜狗微信搜索（weixin.sogou.com）已确认关闭。**
- GitHub Issue [chyroc/WechatSogou#342](https://github.com/chyroc/WechatSogou/issues/342) 确认接口失效
- 2024年8月 sogou.com 域名停用，微信百科上线替代搜狗百科
- 搜狗品牌正在被腾讯全面淘汰

**剩余可行路径评估：**

| 路径 | 可行性 | 代价 | 说明 |
|------|--------|------|------|
| 微信搜一搜 RPA | ⚠️ 中 | 高 | 影刀/Playwright操作微信客户端或网页版搜一搜，效率极低，不可规模化 |
| 第三方数据服务API | ⚠️ 中 | 中 | 阿里云API市场/聚合数据等提供公众号文章搜索API，按次付费，覆盖90%活跃公众号 |
| 公众号订阅 + Webhook | ⚠️ 低 | 中 | 只对已订阅的公众号有效，覆盖窄，适合精品源追踪 |
| 百度 site:mp.weixin.qq.com | ❌ 低 | 低 | 百度已几乎不收微信内容 |
| 微信公众平台官方接口 | ❌ 极低 | — | 只有公众号运营者自己能调用，不支持跨号搜索 |

**结论**: 微信生态的规模化采集当前几乎不可行。**推荐策略：放弃规模化采集微信，改用"精选公众号订阅 + 第三方API补充"的精简模式。**

---

### 2.2 微博 — 🟢 最可行的起点

**移动端 API（m.weibo.cn）接口稳定，反爬力度低。**

核心接口：
```
# 关键词搜索
GET https://m.weibo.cn/api/container/getIndex?containerid=100103type=1&q={关键词}&page=1

# 热搜榜
GET https://weibo.com/ajax/side/hotSearch

# 评论
GET https://weibo.com/ajax/statuses/buildComments?mid={微博ID}&max_id=0
```

关键要求：
- 需要有效的 Cookie（`SUB` 字段），有效期 7-30 天
- 单 IP 建议频率 < 15次/分钟
- 移动端 API 反爬远弱于 PC 端

**期货内容量评估**：搜索"螺纹钢"、"铁矿石"等关键词有大量实时讨论。

---

### 2.3 小红书 — 🟡 可行但需逆向

**2025年10月签名算法大升级**，但社区已跟进破解。

关键技术点：
- 核心签名参数：`X-s`（格式：`XYS_` + CustomBase64(JSON)）
- 签名生成依赖 `window.mnsv2()` 方法，深度绑定浏览器环境
- 两种方案：**浏览器RPC**（稳定但慢）vs **纯算法补环境**（快但需维护）

**活跃开源项目（2026.04 仍在更新）：**

| 项目 | 语言 | 说明 |
|------|------|------|
| [Spider_XHS](https://github.com/cv-cat/Spider_XHS) | Python | PC端+创作者平台全覆盖 |
| [XHS_RS_TOOLS](https://github.com/aki66938/XHS_RS_TOOLS) | Rust+Python | Docker容器化，实时签名 |
| [xhscrawl](https://github.com/submato/xhscrawl) | Python+Node.js | 在线签名服务 |

**推荐方案**：基于 Spider_XHS 二次开发，它是目前最活跃维护的项目。

---

### 2.4 抖音 — 🟡 可行，方案多样

**签名体系**：
- 旧：X-Bogus（MD5+RC4，确定性）
- 新：A-Bogus（SM3+RC4+伪随机，840行JS）

**方案对比**：

| 方案 | 日均请求 | 稳定性 | 复杂度 |
|------|----------|--------|--------|
| MediaCrawler (Playwright) | 数千 | 高 | 低 |
| Python asyncio + execjs | 数万-10万 | 中 | 中 |
| Go 协程池 + 预签名 | 50万+ | 高(92%+) | 高 |

**推荐方案**：
- 验证阶段：MediaCrawler（免去逆向工作，直接验证数据质量）
- 规模化阶段：Go方案或纯后端逆向

---

### 2.5 X/Twitter — 🟡 看预算

**API 价格（Musk收购后）：**

| Tier | 月费 | 读取量 | 关键能力 |
|------|------|--------|----------|
| Free | $0 | 100条/月 | 几乎不可用 |
| Basic | $200 | 15,000条/月 | 无流式 |
| **Pro** | **$5,000** | **1,000,000条/月** | **Filtered Stream** |
| Enterprise | ~$42,000 | 自定义 | 全量Firehose |

**替代路径：**
- Nitter 匿名镜像实例（不稳定，镜像经常下线）
- Guest token + GraphQL 接口（有限制）
- RSSHub 桥接（部分账号可用）

**推荐策略**：
- 初期：RSSHub + 重点账号公开抓取
- 后期：如数据价值验证 → 考虑 Pro tier（期货全球信息$5k/mo可接受）

---

### 2.6 雪球 — 🟢 意外的好选择

雪球是国内最大的投资者社区，**对期货讨论来说价值可能超过微博**：
- 搜索API开放度好
- 用户讨论质量高（真实交易者多）
- 自然包含品种标签、价格讨论、多空观点
- 反爬力度远低于娱乐社交平台

## 三、修正后的平台优先级

```
Tier 1 (立即验证，高ROI):
├── 微博 (m.weibo.cn API)     → 中文期货讨论量最大
├── 雪球 (xueqiu.com API)     → 投资者社区，信息质量最高
└── B站 (api.bilibili.com)    → 视频标题/评论含期货分析

Tier 2 (投入开发，中ROI):
├── 小红书 (Spider_XHS)        → 散户讨论活跃，需逆向投入
├── 抖音 (MediaCrawler)        → 短视频期货分析兴起，需逆向投入
└── X/Twitter (API/抓取)       → 全球期货信息，但API昂贵

Tier 3 (暂缓/替代方案):
├── 微信/公众号 → 放弃规模化，改用"精选源+第三方API"
└── 其他 (Reddit/Telegram/Discord)
```

## 四、可行性验证计划

### 4.1 验证维度

| 维度 | 指标 | 通过标准 |
|------|------|----------|
| **可接入性** | 能否成功发起请求并获取数据 | 200响应 + 有效JSON |
| **内容覆盖** | 期货关键词能否搜到相关结果 | Top 20条中 > 60% 与期货相关 |
| **数据质量** | 单条数据字段完整度 | 正文+时间+作者+互动数据 ≥ 4字段 |
| **频率限制** | 连续请求的封禁阈值 | 至少支持 10 req/min |
| **时效性** | 最新结果的时间延迟 | < 30 min |

