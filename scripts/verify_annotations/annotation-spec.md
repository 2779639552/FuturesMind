# 细粒度中文注释规范(2026-08-12 批次共用)

> 本文件是所有注释批次 agent 的统一作业规范。目标:代码本身能当教材读。
> **本任务只插入/补充注释,绝对禁止改动任何可执行代码、阈值数字、字符串字面量
> (docstring 内容除外)、import 顺序、缩进。** 每批完成后必须通过末尾的门禁。

## 标注层级与标记前缀

| 层级 | 标记 | 对象 |
|------|------|------|
| 函数块 | `# 【功能】` + 可选 `# 【参数】`/`# 【返回】`/`# 【关键】` | 函数上方,`def` 之前 |
| 调用包 | `# 【调用包】` | import 行行尾追加 |
| 调用点 | `# 【调用函数】` | 跨模块/外部API/有数据转换的调用,行尾追加 |
| 变量 | `# 【变量】` | 有含义的配置/阈值/单位/中间结果/状态量,行尾追加 |
| JS | `// 【功能】` 头 + `// 【调用函数】`/`// 【变量】` 行内 | web_template.html 内联 JS |

函数块**保留既有英文 docstring**(在其上方加 `# 【功能】...` 中文注释行,不删除、
不替换英文 docstring)。文件模块级已有"中文导读"docstring 的,允许在其内补充段落。

## 规则 A —— 调用包(import)

每个 import 行行尾追加 `# 【调用包】用途`,写**该包在本文件的用途**,不写翻译。
反例:`import os  # 导入os`(翻译式,禁);正例:`import os  # 【调用包】路径/环境变量操作`。
多名字 `from x import a, b` 一条注释写整体用途即可。`__init__.py` 若仅 re-export,
加一行模块 docstring 说明即可。

## 规则 B —— 调用点(只加"有信息量"的调用)

只给这些调用加 `# 【调用函数】`:
- 跨模块/跨包调用(本包之外的对象方法、图/链调用如 `graph.invoke`、`llm.invoke`);
- 外部 API/系统调用(`requests.get`、`subprocess.run`、`node --check`、平台适配器抓取方法);
- 有数据转换、隐含约定、副作用重要的调用(如 `_load_price` 带 fallback、`json.dumps` 落盘)。

禁止给 `len()`/`print()`/`range()`/`.append()`/`.get()`/f-string/`isinstance()` 等
琐碎点加注释。批量同模式调用(如循环里对每个品种调同一函数)可在循环上方加一条说明,
不必每行重复。

## 规则 C —— 变量(只加有含义的变量)

只给这些加 `# 【变量】`(行尾追加):
- 配置/常量/阈值(`max_risk_pct`、`TIMEOUT`、`top_n`)、带单位或特殊语义的值;
- 中间结果/状态量(dataclass/TypedDict 字段、线程锁、生成器、有业务含义的容器);
- 魔法数给上下文(如 `* 0.02` 注释"手续费率")。

禁止给单字符变量、循环计数器、自明取值(如 `x = 1` 用于遍历)、临时中转加注释。

## 规则 D —— 函数块(未标注文件才需要全量写)

**已标注文件**(每批 agent 会收到清单):函数块已存在,不要重写,只补缺失段与上面
A/B/C 三档;个别确实没有函数块的非平凡函数可补一个。

**未标注文件**:对每个 public 函数和非平凡 private 函数,在 `def` 上方加中文注释块:
```
# 【功能】一句话讲清做什么、产出什么。
# 【参数】param1: 含义与单位。
# 【返回】返回什么;异常时怎么办。
# 【关键】值得一提的实现要点(数据来源、fallback、副作用),没有可省略。
```
纯 getter/一行函数可只写 `# 【功能】...` 一行。函数内部关键分支可加少量 `#` 行内注释。

## 规则 E —— 行号稳定与不造假

- 行内注释一律**行尾追加**,不插独立注释行(函数块除外);
- 函数块写在 `def` 上方注释行,不移动 `def/class` 行;
- 拿不准用途的标 `# 【待确认】…`,**绝不编造用途**;
- 不删除、不改写任何既有代码与英文注释。

## 门禁(每批完成后必须全过,失败自行修复)

```bash
venv/Scripts/python.exe scripts/verify_annotations/ast_normalize_compare.py <本批文件...>
venv/Scripts/python.exe scripts/verify_annotations/dup_block_scan.py <本批文件...>
venv/Scripts/python.exe -m py_compile <本批 .py 文件...>
```
- `ast_normalize_compare` 必须全 PASS —— 它证明零逻辑改动(注释不进 AST);
- `dup_block_scan` 必须无"新增重复代码块"—— 证明没有复制粘贴代码;
- `py_compile` 证明语法完好。
- 前端批次额外:`venv/Scripts/python.exe scripts/verify_annotations/node_check_html.py web_template.html`

**不要跑全量 pytest**(主会话在 P3 统一跑)。若你想快速自检,可只跑与本批强相关的一两个测试文件。
